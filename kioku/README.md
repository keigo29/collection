# KIOKU — 暗記カード

[Anki](https://apps.ankiweb.net/) と同じ考え方（間隔をあけてくり返す）で覚える、ブラウザで動く暗記カードです。
Workstation のデザインルール（モノトーン・ピル型のボタン・24px の角丸・ライト／ダーク）で作っています。

- パソコンでもスマホでも使えます（スマホでは「ホーム画面に追加」でアプリのように使えます）
- 通信がなくても学習できます。データは端末の中（IndexedDB）に置きます
- **サーバーを持たないので運用費は 0 円**です。公開は GitHub Pages、端末どうしの同期は GitHub の Gist（ひみつのメモ置き場）を使います

## 公開のしかた（はじめの1回だけ）

1. このリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. `main` に入れると、自動で `https://<ユーザー名>.github.io/collection/kioku/` に公開されます

> リポジトリが非公開（Private）のときは、GitHub の無料プランでは Pages を使えません。公開（Public）にするか、Cloudflare Pages など無料の置き場に `kioku/dist` を置いてください。データは各自の端末と各自の Gist にあるので、ページを公開しても中身は見えません。

## スマホとパソコンで同期する

1. GitHub で [gist の権限だけの鍵](https://github.com/settings/tokens/new?scopes=gist&description=KIOKU) を作る
2. アプリの **設定 → 同期** に貼りつけて「つなぐ」
3. もう一方の端末でも同じ鍵を貼りつける

開いたときと学習を終えたときに自動で同期します。同じカードを両方で答えたときは、あとのほうが残ります。

## 開発

```sh
cd kioku
npm install
npm run dev     # 開発用のサーバー
npm test        # 出題の計算・検索・カードの型・同期のまぜ方などのテスト
npm run build   # dist/ に書き出す
```

- フォント（Inter）とアイコン（Lucide）、数式（KaTeX）、SQLite（sql.js、.apkg 用）はすべて同梱です。外の CDN は読みません
- 色はすべて `src/style.css` の `:root` のトークンで、ダークは同じ名前を入れかえるだけです
